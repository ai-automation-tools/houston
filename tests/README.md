## Checking the real app

| Command | What it does | Takes |
|:---|:---|:---|
| `npm run smoke` | Launches the app on a throwaway profile and runs about two dozen named checks against it (listed below), each printed as PASS, FAIL, SKIP or WARN and written to `.smoke/summary.json`, with screenshots saved next to it. Checks that need Project Hub or Cronsole count only with `--live` (`npm run smoke -- --live`); a failed screenshot (a locked display) is a warning. Exits 1 when a check fails, when the app quits without running them (another instance on the same profile), or after 120 s. | 30 to 80 s |
| `npm run spike:extensions` | Installs LastPass and Rakuten from the Web Store, loads a shop page, and logs each extension's errors. Rerun on every Electron upgrade. | about 60 s |
| `npm run demo` | Builds the browser demo into `_site/`. Preview it with any static server (`python -m http.server -d _site`) and check the sidebar, a terminal (`npm test`), and the confirm bar after six seconds. | a second |

What the smoke run checks:

- **Browser:** a tab loads example.com; find in page counts matches and closes.
- **Terminals:** one opens at start; the shell menu offers PowerShell 7, and Command Prompt starts as not-PowerShell.
- **MCP:** a call without the token is refused and one with it answered; `list_tabs`, `open_tab`, `read_tab`, `sidebar_search`, `list_terminals` and `cron_tasks` answer; `terminal_run` puts the exact command on the bar, the check clicks Run, and `terminal_read` reads back what it printed (including the MCP address the terminal was given); `run_status` reports that run succeeded with exit code 0, a second failed with exit code 3, and a third cancelled by clicking its tab's ×, and the MCP panel's Agent work lists those three with how each ended; the MCP panel and `mcp.log` list the same calls.
- **Shell UI:** 💬 opens the chat pane beside Files and the browser area narrows by its width; the chat never receives the key, + page puts the tab in the context tray with its exact text and destination, and ✕ takes it out; a workspace switch swaps the tabs and terminals and switching back restores them; Ctrl+K opens the palette and Enter runs the top match; the status dot opens Connections with every row, and Retry rechecks one; a seeded old `chat.json` becomes the first conversation, and search, rename, New, reopen and delete work; a throwaway repo opened as a workspace lists its staged, unstaged and untracked files in the Git tab, and a click opens the diff as a script-free page; a throwaway `package.json` opened as a workspace starts its dev server from the Dev tab, which shows the address it printed, serves its log as a script-free page, restarts it with a new pid and stops it.
- **With `--live`:** the Files tree loads and expands, search finds README files, a Markdown file opens as a document page with no second sidebar, the Cron tab lists Cronsole's tasks with one pinned Cronsole tab first, and a task's run opens as a page.

> [!NOTE]
> `npm run smoke` and `npm run spike:extensions` open a real window on a throwaway profile under `%TEMP%` (deleted afterwards, with only your `settings.json` copied in), so they run beside an open copy of the app and leave your history, logs and extensions alone. `npm run smoke -- --profile` uses the real profile in `%APPDATA%\ai-command-center` instead; it then won't run while the app is open.
