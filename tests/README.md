The unit tests use Node's built-in runner, so there's nothing to install beyond the app itself. They cover the code with logic in it; the Electron wiring is covered by the smoke run instead, because mocking Electron would test the mock.

## Checking the real app

| Command | What it does | Takes |
|:---|:---|:---|
| `npm run smoke` | Launches the app on a throwaway profile and runs about two dozen named checks against it (listed below), each printed as PASS, FAIL, SKIP or WARN and written to `.smoke/summary.json`, with screenshots saved next to it. Checks that need Project Hub or Cronsole count only with `--live` (`npm run smoke -- --live`); a failed screenshot (a locked display) is a warning. Exits 1 when a check fails, when the app quits without running them (another instance on the same profile), or when the run stops before its end: the launcher kills it after 240 s, and `summary.json`, written after every check, then holds the checks it reached with `complete: false`. The exit code is the summary's verdict; a crash as the app quits is printed as a note. | 30 to 80 s |
| `npm run spike:extensions` | Installs LastPass and Rakuten from the Web Store, loads a shop page, and logs each extension's errors. Rerun on every Electron upgrade. | about 60 s |
| `npm run demo` | Builds the browser demo into `_site/`. Preview it with any static server (`python -m http.server -d _site`) and check the sidebar, a terminal (`npm test`), and the confirm bar after six seconds. | a second |

What the smoke run checks:

- **Browser:** a tab loads example.com; find in page counts matches and closes; typing in the address bar suggests a Recent page, ↓ highlights it and Escape closes the list.
- **Terminals:** one opens at start; the shell menu offers PowerShell 7, and Command Prompt starts as not-PowerShell.
- **MCP:** a call without the token is refused and one with it answered; `list_tabs`, `open_tab`, `read_tab`, `sidebar_search`, `list_terminals` and `cron_tasks` answer; `terminal_run` puts the exact command on the bar, the check clicks Run, and `terminal_read` reads back what it printed (including the MCP address the terminal was given); `run_status` reports that run succeeded with exit code 0, a second failed with exit code 3, and a third cancelled by clicking its tab's ×, and the MCP panel's Agent work lists those three with how each ended; the run search finds the failing one by its output, a click opens its log as a script-free page, and `runs.json` has all three; the MCP panel and `mcp.log` list the same calls.
- **Shell UI:** 💬 opens the chat pane beside Files and the browser area narrows by its width; the chat never receives the key, + page puts the tab in the context tray with its exact text and destination, and ✕ takes it out; a workspace switch swaps the tabs and terminals and switching back restores them; Ctrl+K opens the palette and Enter runs the top match; the status dot opens Connections with every row, and Retry rechecks one; a seeded old `chat.json` becomes the first conversation, and search, rename, New, reopen and delete work; a throwaway repo opened as a workspace lists its staged, unstaged and untracked files in the Git tab, and a click opens the diff as a script-free page; a throwaway `package.json` opened as a workspace starts its dev server from the Dev tab, which shows the address it printed, serves its log as a script-free page, restarts it with a new pid and stops it.
- **Agents (Windows):** against a throwaway Core under `.test-tmp/`, never the running one: **Start** opens a contained shell tab in the workspace folder and a command typed in it writes a file there; an approval card's **Deny** gives a contained `curl.exe` a 403 and **Allow for this session** lets a repeat through without asking; the row's **Stop** ends the session; and the navbar's **Stop All** ends two running sessions in under 5 s, says how many, and is audited as `stop.all`, with Ctrl+Shift+Backspace on the menu item; the Logs tab lists those events newest first, Denied shows only denials (the refused CONNECT among them), Only this session narrows to one, and a click shows an event whole; a session's **Transcript** opens as a script-free page where a made-up key it echoed shows only as `[REDACTED:anthropic-key]`; ⚙ opens Settings with a table per scope and the Core's limits and counts from that Core; and the Integrations tab shows a server registered with `ctl` with its command, **Install** reads its three tools and **Pin 3 tools** serves them, and a standing grant made with `ctl` is listed with who it runs as and is paused and resumed from the tab.
- **With `--live`:** the Files tree loads and expands, search finds README files, a Markdown file opens as a document page with no second sidebar, the Cron tab lists Cronsole's tasks with one pinned Cronsole tab first, and a task's run opens as a page.

> [!NOTE]
> `npm run smoke` and `npm run spike:extensions` open a real window on a throwaway profile under `%TEMP%` (deleted afterwards, with only your `settings.json` copied in), so they run beside an open copy of the app and leave your history, logs and extensions alone. `npm run smoke -- --profile` uses the real profile in `%APPDATA%\ai-command-center` instead; it then won't run while the app is open.
