## Unreleased

**Changed**

- **Downloads, and Save page as** (2026-11-27). *UI/UX audit.* Houston did nothing of its own with a download. Now a download goes to your Downloads folder under a name that overwrites nothing, a note says when it starts and how it ended with **Show in folder**, and it's listed in Recent, where a click shows it in Explorer. Houston never opens or runs one, and it keeps Windows' mark of the web. **Save page as…** (Ctrl+S, File, or a web page's right-click menu) saves the whole page where you pick and lists it the same way. Show in folder works only for a file Recent got from a download. Corner notes now stack instead of covering each other.
- **Houston fits a small window, and Stop All stays on screen** (2026-11-27). *UI/UX audit.* The smallest window was 900×600, taller than a 1080p screen at 200% scaling allows. It's 800×480 now. At that size with the chat open, the address box had pushed **Stop All** off the window, and the Cron buttons ran past the sidebar. The sidebar and chat now give way to at most a third of the width each and the terminal to 40% of the height, a narrow address bar drops Forward, ↗, 💬 and the extension icons (each has another way in), and the Cron buttons wrap. `npm run smoke` checks every sidebar tab, Settings and the palette at the smallest size with the chat open.
- **Roadmap: no View source; Downloads with Save page as; a window-size pass** (2026-11-27). *UI/UX audit.* Owner's calls: the page menu gets no View source, since **Inspect** shows the source and the navigation rule stays as it is. Save page as joins the Downloads item, and the zoom pass becomes a window-size pass at the minimum size and at 200% scaling.
- **Sidebar tabs show icons and names by default** (2026-11-27). *UI/UX audit.* A new install showed the twelve sidebar tabs as icons only, so a new user had to hover each to learn it. The default is now an icon and its name (owner's call); tabs that don't fit still go behind **»**. A choice already saved in **Settings › General › Sidebar tabs** is kept.
- **Electron 45.4.1 installed, as the lockfile says** (2026-11-27). *UI/UX audit.* `node_modules` held 45.2.3. Reinstalled with `npm ci`; the Houston Core keeps `koffi.node` open, so its logon task was ended first and started again after. Smoke passes 55 of 55 on the new install.
- **Terminal right-click no longer pastes on its own** (2026-11-27). *UI/UX audit.* With nothing selected, a right-click in a terminal sent the clipboard straight to PowerShell, which ran it; the audit's own test ran a stray fragment that way. It now opens a menu whose **Paste** item shows the clipboard's first line and how many lines it has, and pastes only on that click; **Select all** and **Clear** are there too. A right-click on a selection still copies it, and Ctrl+V still pastes. Native menus also show `&` now instead of reading it as a mnemonic.
- **Ctrl+K reaches every sidebar tab** (2026-11-27). *UI/UX audit.* The palette had **Show …** actions for seven of the twelve tabs: News, Feed, Agents, Logs and Integrations were missing, and "Show Agents" found files. The actions now come from the sidebar's own tab buttons, and `npm run smoke` checks each one.
- **A warning when the installed Electron isn't the lockfile's** (2026-11-27). *UI/UX audit.* The audit found Electron 45.2.3 in `node_modules` against 45.4.1 in `package.json` and the lockfile. `npm run smoke` now warns, and `npm run gate` refuses, naming both versions (`electronDrift()` in `abuse/gate.js`).
- **Right-click menus on browser tabs and the shell's own fields** (2026-11-27). *UI/UX audit.* A tab has Reload, Duplicate, Copy address, Close, Close other tabs and Close tabs to the right; the pinned Cronsole tab is never closed by the last two. The address bar, the search box, the chat box and the Settings fields have Cut, Copy, Paste and Select all. A web page's menu adds **Print…**.
- **Bookmarks and Recent rows have a right-click menu** (2026-11-27). *UI/UX audit.* A page opens in a new or background tab or the default browser, or copies its address; a Recent folder or terminal opens a terminal there or copies its path, and a Recent file opens in VS Code or copies its Hub id.

- **No crash on quit** (2026-11-27). Houston often exited with `0xC0000409` or `0xE06D7363` instead of 0 (2 of 3 smoke runs). It kills every terminal as its window closes, and node-pty stops each one's ConPTY output thread one second later, so Electron was tearing the process down with those threads still running. A crash dump showed the exception thrown in node-pty's `conpty.node`. `will-quit` now holds the quit until 1.5 s after the last terminal ended (`ptyDrainMs()` in `src/main/terminal.js`), then quits again. That's no wait when no terminal ended recently, and the window is already gone. Four smoke runs then exited cleanly with no crash dump. A profile switch's relaunch still works, since `app.relaunch()` starts the new instance only once this one has exited.
- **A smoke run no longer needs the desktop to itself** (2026-11-27). A smoke run (only) now starts with `disable-renderer-backgrounding`, `disable-backgrounding-occluded-windows` and `disable-background-timer-throttling`. With the window kept off-screen the whole run, it went from 50 of 53 to 53 of 53. A minimized window still fails four capture and find checks, since it has nothing on screen. The real app keeps the throttling, which saves power.
