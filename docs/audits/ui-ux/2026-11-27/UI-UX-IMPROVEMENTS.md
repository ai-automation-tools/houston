# UI/UX improvements

These are recommendations based on observed screens. They are not defects unless linked to BUG-01.

| ID | Current experience / problem | Proposed experience and benefit | Implementation guidance | Priority / effort |
|---|---|---|---|---|
| U01 | Twelve sidebar areas use 32 px icon buttons by default; names are only in accessible descriptions/tooltips. New users must learn the icon map. | Show names by default, or offer a first-run Icons / Names choice. Keep icon-only mode for experienced users. | Change the default `tabLabels` in shared preferences and preserve explicit user choice; use existing `side-tabs[data-labels]` CSS. | P2 / Small |
| U02 | Cron showed a long list from an account with 500 tasks; locating a task requires scrolling. | Add in-panel search by task name and a status/platform filter, with a visible count. Reduce time to a known task. | Filter cached `cronTasks` in `src/renderer/sidebar.js`; retain Docs filter and show active filters in the header. | P2 / Medium |
| U03 | Git, Dev and Agents correctly explain that the Default workspace has no folder, but only describe the prerequisite. | Add a direct “Choose folder workspace” button or link to the Files tree and a brief instruction. Reduce dead-end navigation. | Reuse the existing workspace switcher/files flow; do not let a renderer-supplied path bypass Hub. | P2 / Small |
| U04 | Integrations lists a server, sixteen tools, a secret name, grant and backends in one narrow pane. Tool descriptions are clipped in the 438 px sidebar. | Start with compact server/grant summaries and expand a selected item into a readable detail view. Make safety state and next action easy to scan. | Update `renderIntegrations` in `src/renderer/sidebar.js`; keep unconfined status prominent. | P2 / Medium |
| U05 | Logs shows many event rows and three filters in a narrow sidebar. | Add a stronger event-type/date grouping and a persistent filter summary; keep full details on selection. Improve triage. | Use existing filter helpers in `src/shared/logs.js`; avoid loading more rows by default. | P2 / Medium |
| U06 | Small secondary labels and hint text occur throughout the dense sidebar and Settings (`11–12px` in `styles.css`). | Verify contrast and text readability at 100% and 200% zoom; raise size/contrast where measured insufficient. | Introduce shared secondary-text tokens, then manually inspect both themes. | P3 / Small |
| U07 | News and Feed empty states explain configuration file keys but send users to docs by text only. | Give a clickable setup guide and a read-only configuration status panel. Reduce setup hunting. | Use the app's existing internal docs route; avoid exposing secrets or writing settings automatically. | P3 / Small |
| U08 | Command palette is a strong interaction pattern but incomplete (BUG-01). | Every sidebar area should be available through the same “Show …” action language. | Share one panel registry between sidebar and palette, then add smoke coverage. | P1 / Quick Win |
| U09 | Terminal right-click pastes clipboard content immediately when no text is selected; the live test caused PowerShell to evaluate a pasted fragment. | Show a Paste menu item or confirmation before sending clipboard text to a live shell, while retaining explicit keyboard paste. Reduce accidental command execution. | Change the `contextmenu` handler in `src/renderer/terminal.js`; test with harmless clipboard text on a disposable terminal and preserve copy-selection behavior. | P1 / Small |
| U10 | Browser tabs have no context menu. | Offer Reload, Duplicate, Copy address, Close, Close others and Close to right where applicable. Improve standard browser discoverability. | Reuse tab methods in `src/renderer/app.js` and `src/main/tabs.js`; preserve existing close/reopen behavior. | P2 / Small |
| U11 | Shell search and address fields have no right-click edit menu. | Offer Cut, Copy, Paste and Select all. Make mouse editing predictable. | Add a shell-only editable-control context handler; do not change web page menus or terminal paste. | P2 / Small |
| U12 | Imported bookmarks and Recent items have no context menu. | Add Open in new tab/default browser and Copy address/path where applicable. Reduce extra navigation. | Keep imported bookmark modification with the source browser; use existing `openUrl` and clipboard helpers. | P3 / Small |
| U13 | Web page background menu offers navigation, extensions, attachment and Inspect but no Print, Save page or View source. | Consider these standard browser actions on `http(s)` pages if they fit Houston's browser scope. | Implement in `src/main/tabs.js`; keep internal `acc://` pages restricted. | P3 / Medium |

## Accessibility and visual checks to perform next

The observed accessibility tree named major tabs, buttons, dialogs and fields, and Ctrl+K responded to keyboard input. This does not establish WCAG 2.2 AA conformance. Run measured color contrast, 200% zoom, keyboard focus-order, modal focus-return, and screen-reader checks on the shell, Settings, palette, Cron, Logs and Integrations. Test light and dark modes. Do not claim responsive support from the 1488 × 944 desktop capture.
